Unity game development project for CISC 4900.

A 3D action combat based game loop donning a low-fidelity theme, revolved around testing the mettle of the players reaction and wits in the face of a variety of opponents.

Build: https://gnailj.itch.io/grit 
Only for windows PC for now.
To test, extract the .zip folder and run the "4900Project" file.

Dev Board: https://trello.com/b/eFhdV003/4900project-grit
